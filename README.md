## Tema e objetivo

Aprender como SQL pode ser utilizado para analisar dados operacionais, identificar problemas em processos, calcular indicadores e apoiar decisões de negócio.

## Diretriz do notebook

O NotebookLM foi configurado para atuar como assistente de estudos de SQL aplicado a Operations e Business Analysis.

A orientação foi utilizar apenas as fontes fornecidas, explicar os conceitos de forma objetiva e priorizar exemplos relacionados a tickets, backlog, SLA, tempo de resolução, volume de casos, produtividade e recorrência de incidentes.

## Pergunta realizada

**Quais conceitos de SQL são mais importantes para analisar dados operacionais, como tickets, backlog, SLA, tempo de resolução e recorrência de problemas?**

### Resposta

O NotebookLM destacou cinco grupos principais de conceitos:

- funções de data e hora;
- window functions;
- `CASE WHEN`;
- `GROUP BY` e `HAVING`;
- `JOINs`, CTEs e subconsultas.

Esses recursos podem ser utilizados para calcular tempo de resolução, acompanhar backlog, identificar recorrências, analisar cumprimento de SLA, agrupar indicadores e combinar dados de diferentes tabelas.

### Fontes citadas na resposta

A resposta utilizou principalmente:

- Snowflake Documentation — funções de data e hora;
- DbGate — window functions;
- Querio — agregações, lógica condicional e JOINs;
- Freshworks — métricas relacionadas a SLA.
